# How to open Forge Synesis

Currently, Forge Synesis can be opened directly in JabRef using the following keyboard shortcut:

#### Alt + 2

* Start JabRef.

* Press Alt + 2 on your keyboard.

* The Forge Synesis side panel will open.

Note: Currently, the keyboard shortcut is the only available way to open Forge Synesis. A toolbar button or other menu option is not yet available.
